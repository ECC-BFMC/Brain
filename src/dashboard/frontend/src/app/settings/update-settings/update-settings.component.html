The car couldn't read {{ sourceUrl || 'this repository' }} because it has no credentials for it. The dashboard never stores tokens — instead you give the Pi its own read access, once. Pick whichever matches your repo URL:

SSH deploy key your URL for git@ / ssh:// URLs

On the Pi (over SSH), create a key and add it to your repo:

ssh-keygen -t ed25519 -C "bfmc-car" -f ~/.ssh/id_ed25519 -N ""
cat ~/.ssh/id_ed25519.pub

Copy that printed public key into your repo on GitHub under Settings → Deploy keys → Add deploy key (read-only is enough), then test: 

ssh -T git@github.com

Make sure your repository URL above uses the SSH form, e.g. git@github.com:your-user/your-fork.git.

HTTPS access token your URL for https:// URLs

Create a fine-grained Personal Access Token with read access to the repo, then store it on the Pi so git reuses it:

git config --global credential.helper store
git -C ~/Brain fetch   # paste username + token once when prompted

Adjust the path if your code isn't in ~/Brain.

Once access is set up, close this and press Check again.
